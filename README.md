# SplittyCat

Веб-приложение для учета совместных расходов

## Концепция

Совместные расходы - расходы, которые делаются группой людей, и один человек из группы платит сразу за всех

Например, друзья идут в ресторан, им приносят общий счет, кто-то один оплачивает этот счет

### Проблематика

Нужно запомнить когда была сделана трата, размер траты, кто заплатил, и какие доли у участников траты

Если траты совершаются в рамках одного мероприятия, то полезно запомнить и это

Например, субботняя прогулка в рамках которой друзья сходили в ресторан и покатались на коньках (кто-то один оплатил счет и аренду коньков)

### Решение

Веб-приложение позволяет создать событие (мероприятие) в рамках которого можно создать несколько трат, которые описываются суммой, плательщиком, участниками и их долями
