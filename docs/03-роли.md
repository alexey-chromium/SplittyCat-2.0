# Роли

## Глобальные роли

- Незарегистрированный пользователь (`НП`) - пользователь, который не прошел процедуру регистрации
- Зарегистрированный пользователь (`ЗП`) - пользователь, который прошел процедуру регистрации

## Контекстные роли

- Создатель события (`СС`) - пользователь, который создал конкретное событие
- Авторизованный участник события (`АУС`) - зарегистрированный пользователь, который перешел по ссылке-приглашению и привязался к слоту в рамках конкретного события
- Создатель траты (`СТ`) - пользователь, который создал трату в рамках конкретного события
- Просматривающий (`П`) — пользователь, открывший событие по ссылке-приглашению, но еще не привязанный к участнику события
