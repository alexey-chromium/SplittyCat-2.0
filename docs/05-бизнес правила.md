# Бизнес правила

## Общие правила

### BR-001
Событие может создать только зарегистрированный пользователь.

### BR-002
Поделиться событием можно только по действительной ссылке-приглашению.

### BR-003
Действительная ссылка-приглашение может быть заменена новой ссылкой-приглашением, при этом предыдущая ссылка становится недействительной.

### BR-004
Заменить ссылку-приглашение может только создатель события.

### BR-005
Открытие события по ссылке-приглашению не требует обязательной привязки пользователя к участнику события.

### BR-006
Пользователь, открывший событие по действительной ссылке-приглашению, может просматривать данные события.

## Правила по участникам

### BR-007
Участник события может существовать без привязки к зарегистрированному пользователю.

### BR-008
Один зарегистрированный пользователь не может быть привязан более чем к одному участнику
в рамках одного события.

### BR-009
Создатель события должен быть привязан к своему слоту.

### BR-010
Пользователь должен быть привязан к участнику события, чтобы выполнять действия участника события.

### BR-011
Привязаться к участнику события может только зарегистрированный пользователь.

### BR-012
Зарегистрированный пользователь может привязаться только к свободному слоту в рамках события.

### BR-013
Зарегистрированный пользователь может создать только один новый слот в рамках события и сразу привязаться к нему, если подходящего свободного слота нет.

### BR-014
Пользователь может отвязаться только от того участника события, к которому он сам привязан.

### BR-015
Создатель события не может отвязаться от участника события, к которому он привязан.

### BR-016
Участник события не может быть удален, если к нему привязан пользователь.

### BR-017
Участник события не может быть удален, если он состоит в доле хотя бы в одной трате.

## Правила по тратам

### BR-018
Трата должна относиться ровно к одному событию.

### BR-019
У траты должен быть ровно один плательщик.

### BR-020
Плательщик траты должен быть участником того же события, к которому относится трата.

### BR-021
Каждая доля участника должна относиться к одной конкретной трате и одному конкретному участнику события.

### BR-022
Сумма всех долей по трате должна быть равна сумме траты.

## Правила по правам

### BR-023
Создать трату может только пользователь, привязанный к участнику события.

### BR-024
Создать свободный слот может любой авторизованный участник события.

### BR-025
Удалить событие может только создатель события.

### BR-026
Удалить трату может только ее создатель или создатель события.

### BR-027
Удалить свободный слот может любой авторизованный участник события.
