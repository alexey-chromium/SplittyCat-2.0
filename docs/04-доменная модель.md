# Доменная модель

## Пользователь

Зарегистрированный пользователь

#### Атрибуты

- Имя
- Почта

#### Связи
- Может создать много событий
- Может быть привязан к участникам разных событий
- Не может быть привязан более чем к одному участнику в рамках одного события

## Событие

Событие, в рамках которого группа людей создает траты и ведет учет общих расходов

#### Атрибуты

- Название
- Код для приглашения
- Дата начала события

#### Связи
- Создается одним пользователем
- Содержит много участников события
- Содержит много трат

## Участник события

Участник конкретного события

#### Атрибуты

- Имя

#### Связи
- Принадлежит одному событию
- Может быть не привязан ни к одному пользователю
- Может быть привязан не более чем к одному зарегистрированному пользователю

## Трата

Трата в рамках события

#### Атрибуты

- Название
- Сумма
- Дата траты

#### Связи
- Принадлежит одному событию
- Создается одним пользователем
- Имеет одного плательщика
- Содержит много долей

## Доля участника

Доля участника в конкретной трате

#### Атрибуты

- Сумма
- Описание

#### Связи
- Относится к одному участнику события
- Принадлежит одной трате

### Примечания

**Слот** - это понятие, возникающее из-за того, что у сущности **Участник события** может быть опциональная привязка к зарегистрированному пользователю. Это нужно для того, чтобы можно было создать событие, создать участников события, создать траты, а только потом отправить ссылку-приглашение пользователям.

Пользователь может открыть событие по ссылке-приглашению без обязательной привязки к участнику события.

Зарегистрированный пользователь может:
- занять свободный слот в событии
- создать новый слот для себя, если подходящего свободного слота нет
- отвязаться от своего слота, чтобы выбрать другой слот

Незарегистрированный пользователь не может привязаться к слоту.

Создатель события должен быть привязан к своему слоту и не может отвязаться от него.

**Долг** не является отдельной сущностью доменной модели и представляет собой вычисляемое значение на бэке.
