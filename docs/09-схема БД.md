### Инварианты, которые не отражены на схеме БД

Эти инварианты проверяются на уровне кода:

- `expenses.payer_participant_id` должен ссылаться на участника **того же события**, что и `expenses.event_id`.
- Каждый `expense_shares.participant_id` должен ссылаться на участника **того же события**, к которому относится трата `expense_shares.expense_id`.
- Сумма всех долей по трате должна быть равна сумме самой траты.
- У каждой траты должна быть хотя бы одна доля.
- Поле `updated_at` должно обновляться backend-логикой при каждом изменении записи.

CREATE INDEX idx_events_created_by_user_id

CREATE INDEX idx_expenses_payer_participant_id

CREATE INDEX idx_expenses_created_by_participant_id

CREATE INDEX idx_expense_shares_expense_id
